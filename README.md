# Plano 7

## Sobre o Projeto

O **Plano 7** é uma aplicação focada em saúde e bem-estar que calcula o metabolismo do usuário (TMB e GET) e gera um planejamento nutricional personalizado de 7 dias, enviado diretamente via WhatsApp.

## Tecnologias Utilizadas

- **Framework:** React 18 + Vite
- **Estilização:** Tailwind CSS
- **Componentes:** shadcn/ui
- **Banco de Dados:** Supabase
- **Animações:** Framer Motion

## Como rodar localmente

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`

## Deploy

O projeto está configurado para ser publicado em qualquer plataforma de hospedagem estática (Vercel, Netlify, etc).
